## The line

> Diagnosis: after 4,096 sessions, your love language is 'typing...' and then deleting it.

## How it works

`main.ts` (Node 22) deterministically writes the line to `/output/entry.txt` — nothing else, no network, no relative writes.

```sh
node main.ts
cat /output/entry.txt
```
